# Enchufe Virtual
**Version 2.0.0**

Enchufe Virtual is an open source project to showcase software, stores, and digital experiences built with Next.js. This version marks the complete transition from React Router to Next.js, with improvements in routing, performance, UX, and design.

## What was done in this version
- Migration from `react-router-dom` to **Next.js App Router**.
- Added a **store** to showcase and sell tech products.
- Created dedicated views for each project and category.
- New project sections: **open source**, **client work**, and **personal projects**.
- Improved user experience and global styles.
- Improved overall performance and site loading.

## What the project includes
- Optimized navigation with Next.js.
- Dynamic routes generated from `app/search/[slug]/page.jsx`.
- Static pages exportable to GitHub Pages.
- Responsive interface with Hero, Main, Footer, and project views.
- Category system to explore different collections.

## How to use
1. Install dependencies:

```bash npm install 

``` 2. Run in dev mode: 

```bash npm run dev 

``` 3. Build for production: 

```bash npm run build 

``` 4. Preview exported site: 

```bash npm run preview 

``` ## Deploy to GitHub Pages The project is ready to export static content with Next.js and deploy to GitHub Pages. 

```bash npm run predeploy npm run deploy 

``` > Make sure `homepage` in `package.json` points to your site or correct domain.
